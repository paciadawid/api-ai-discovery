# Block 6: the pipeline

**Goal:** your tests run on a clean machine without you, with your credentials only as secrets.

1. **Your repo.** You made it from the template in block 0. Run `git status` first: `.env` must not appear. Commit what you have and push to your repo. (Started from the ZIP? Create an EMPTY repository on GitHub, then `git init -b main`, `git add .`, commit, add the remote and push.)
2. **Turn the pipeline on.** `mkdir -p .github/workflows && cp workshop/pipeline.yml .github/workflows/`, commit, push.
3. **Secrets.** Repo → Settings → Secrets and variables → Actions → add `TOOLSHOP_EMAIL` and `TOOLSHOP_PASSWORD`. Type them in the browser; do not paste them anywhere else.
4. **Green run.** Actions tab → open the run → download the `playwright-report` artifact and open `index.html`.
5. **The escape room.** Replace the workflow with `workshop/escape-room/api-tests.yml`, push, watch it fail. Fix the problems **one at a time**, one commit each. Use **prompt 06** (`workshop/prompts.md`): give the agent the failing log (**redact anything secret first**) and make it classify the cause before it fixes anything.

**Done when:** the pipeline is green with the original workflow's behaviour, and you can say for each escape-room fix whether it was *config*, *environment*, *test* or *application*.

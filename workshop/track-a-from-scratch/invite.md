# Invite for participants (send a few days ahead)

Subject: TestWarez 2026, "From prompt to pipeline": what to bring

Bring a laptop where you may install tools. Please check these before the day; it saves us the first half hour.

1. **Node.js 20.12 or newer** (`node -v`).
2. **An IDE with an AI coding agent you already use**: GitHub Copilot, Cursor, Cline, Claude Code, ... Any works. Check that you are signed in and the agent answers.
3. **A Postman account** (free is fine) with the desktop app, or the web app if you cannot install.
4. **A GitHub account** where you may create a private repository and set Actions secrets.
5. **A short nick** (letters and digits). It goes into the e-mail of your test user.
6. The kit is a GitHub template repository (https://github.com/paciadawid/prompt-to-pipeline-kit): **Use this template**, clone your own copy, run `npm ci` and `npm run preflight`. You want `Pre-flight OK`.

Nothing else: no browser install for the tests, no paid AI plan beyond what you already use. You do not need to know TypeScript well; you will read more than you write.

Corporate laptop with a proxy or locked npm? Tell us now and we will pair you with someone.

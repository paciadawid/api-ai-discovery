# Bearstore workshop repo

- Two folders: `workshop/` (facilitator material, tracks A and B) and `solution/` (the demo project). Read `README.md` first.
- Work on the demo project from `solution/`: its `CLAUDE.md` and `.claude/` apply there. Run `npm test` and `npm run verify` inside `solution/`.
- Workshop kits under `workshop/` have their own `CLAUDE.md` and `.claude/`; they are hand-outs, not the live project.
- Never read or print `.env` contents; never hard-code credentials.
